# Sounds

End-of-stage sounds played by the extension. All three come from Freesound and are released under
**Creative Commons 0** (public domain dedication): they may be copied, modified and redistributed
without permission or attribution. Sources are listed here anyway, so the origin of every file is clear.

| File | Source | Author | Licence | Changes |
|---|---|---|---|---|
| `chime.ogg` | [Soft-Notifications - Bell - Ding-Dong](https://freesound.org/people/LegitCheese/sounds/571513/) | LegitCheese | CC0 | trimmed to 0.8 s, 120 ms fade-out, mono, loudness raised |
| `bell.ogg` | [Thin bell ding 1](https://freesound.org/people/Khrinx/sounds/333696/) | Khrinx | CC0 | trimmed to 1.6 s, 700 ms fade-out, mono, loudness matched |
| `soft.ogg` | [Kalimba (C-note)](https://freesound.org/people/foochie_foochie/sounds/331047/) | foochie_foochie | CC0 | leading silence removed, trimmed to 2.24 s, fade-out, mono, loudness matched |

Format: Ogg Vorbis, 44.1 kHz, mono, quality 4, each file under 20 KB. The three files are levelled
to a similar peak loudness (about −17 to −20 LUFS momentary, peaks below −1 dBFS), so switching sounds
in Settings does not change the volume noticeably.

To replace a sound, use another Creative Commons 0 recording, keep it under 3 s and 50 KB, and update
this table.
